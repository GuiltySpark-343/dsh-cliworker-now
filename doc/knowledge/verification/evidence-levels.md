# 验证证据必须与结论处在同一层

模型目录读取成功，只能证明这次查询拿到了目录；不能据此认定模型生成、续聊或取消已通过。

## 机制

| 证据 | 可以支持的结论 | 仍需另外验证 |
| --- | --- | --- |
| 源码与规格核对 | 存在某条实现路径及行为约束 | 该路径在目标环境实际可用 |
| 模拟协议、回归测试 | 给定输入下的解析、调度和异常处理符合断言 | 实际 CLI 版本、账号与远端权限 |
| 原生账号或模型目录查询 | 查询来源、目录及本次查询结果 | 订阅是否允许实际调用 |
| 目标系统真实进程 | 对应平台的启动、退出或清理行为 | Desktop 控件交互与模型生成 |
| Desktop 交互、保存文件前后核对 | 用户操作确实触发对应显示或持久化 | CLI 实际执行和工具产物 |
| 真实模型任务的事件、退出状态与产物 | 本次指定版本、账号和模型的执行结果 | 未测模型、其他平台及其他操作 |

一次任务返回“已完成”仍需检查过程事件、退出状态、产物以及清理结果。取消必须核对进程范围确已退出；生成成功不自动证明取消成功。

## 记录边界

在实际记录中保留 CLI／插件／宿主版本、平台、操作、结果及未执行范围。模拟夹具写明“模拟”，订阅拒绝、缺失报告和被跳过用例分别保留。原始日志可能含隐私，公开文档只保留脱敏结论和可公开的实现入口。
