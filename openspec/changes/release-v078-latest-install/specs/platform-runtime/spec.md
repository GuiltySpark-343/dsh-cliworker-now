## ADDED Requirements

### Requirement: Windows 后台引导器退出与长路径元数据
Windows 后台引导器 SHALL 在原生进程已结束并发出退出回执后自然退出，不得因为只写控制通道误保留可读端而持续驻留；原生进程范围清理仍由宿主与 Job 管理。Windows 私有 SQLite 元数据快照 SHALL 使用长路径兼容的文件入口，保留源只读及句柄身份检查。

#### Scenario: 后台命令完成
- **WHEN** 原生后台命令正常或非零退出，回执已发送
- **THEN** 引导器自然退出并保留准确退出码，不依赖超时强制结束，也不打开终端窗口

#### Scenario: 用户目录或隔离快照路径很长
- **WHEN** Windows 原生账号的 SQLite 临时快照路径超过普通 Win32 路径限制
- **THEN** 按同一路径的长路径语义读取或创建快照，不因路径长度误报账号不可读取，不迁移或改写原账号目录
