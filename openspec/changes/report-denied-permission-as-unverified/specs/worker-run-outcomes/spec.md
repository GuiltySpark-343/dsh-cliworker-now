## ADDED Requirements

### Requirement: 额外授权被拒绝后完成的轮次
插件 SHALL 继续拒绝 CLI 的额外权限/授权请求。拒绝后若 CLI 本轮自身正常结束且无其他失败证据，结果 SHALL 为 uncertain（结果待核实），说明 MUST 写明授权已拒绝、请先核查实际产物、不要自动重试；该状态 MUST NOT 宣称成功。被拒绝的工具因拒绝报告的失败 MUST NOT 单独判为工具失败；其他工具失败、轮次失败或中断、非零退出、缺少终态、需要额外交互输入的请求 MUST 仍为失败。拒绝时即中断本轮的协议（Claude Code）仍为失败。

#### Scenario: 拒绝后改用其他方式完成
- **WHEN** CLI 请求执行 shell 被拒绝，随后改用编辑工具完成并正常结束本轮
- **THEN** Worker 状态为结果待核实，保留拒绝诊断与本轮回复，提示先核查实际产物

#### Scenario: 拒绝后仍有其他失败
- **WHEN** 授权被拒绝后，另一个工具失败或本轮以失败结束
- **THEN** Worker 状态为失败，不转为结果待核实
