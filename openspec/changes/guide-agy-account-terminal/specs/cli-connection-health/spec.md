## ADDED Requirements

### Requirement: Antigravity 账号终端引导与自动退出
Antigravity 的登录与退出账号终端 SHALL 由 Host 根据原生终端输出识别步骤，在终端上方显示 Host 固定文案的分步引导；引导 MUST 不转发或渲染 CLI 输出，MUST 不记录或回显用户输入的授权码。退出动作 SHALL 在识别到已登录主界面后由 Host 一次性写入 `/logout` 与回车，并以原生账号状态确认结果；除这一条命令外 Host MUST 不向任何 CLI 账号终端写入内容。登录和退出成功与否 MUST 以原生账号状态确认，不以终端文字推断。

#### Scenario: 点击退出登录
- **WHEN** 用户在已登录的 Antigravity 点击「退出登录」，原生终端显示主界面
- **THEN** Host 写入一次 `/logout` 与回车；原生账号状态变为未登录后显示「已退出 Antigravity」，并在进程范围清理确认后关闭终端、解除占用

#### Scenario: 未登录时退出
- **WHEN** 退出终端启动后显示未登录或文件夹信任询问
- **THEN** 不写入任何内容；未登录时提示无需退出并关闭终端，信任询问时提示由用户选择

#### Scenario: 退出未确认
- **WHEN** 写入命令后限定时间内原生账号仍为已登录
- **THEN** 不再写入，提示用户查看终端，终端保持打开由用户处理

#### Scenario: 登录分步引导
- **WHEN** 用户点击「登录账号」，终端依次显示登录方式菜单和授权码输入
- **THEN** 依次提示用 ↑/↓ 选择 Google OAuth 并回车、在浏览器登录授权后复制授权码并粘贴到终端；菜单重绘不使引导后退

#### Scenario: 粘贴授权码
- **WHEN** 用户在授权码步骤粘贴内容
- **THEN** 醒目提示「授权码已粘贴，请按回车完成登录」；引导与事件中不含所粘贴的内容

#### Scenario: 确认登录
- **WHEN** 用户在粘贴或键入授权码后按回车
- **THEN** 显示正在确认，原生账号状态变为已登录后醒目显示「已登录 Antigravity，可以关闭终端」；限定时间内未确认则提示查看终端，允许粘贴新的授权码后再次回车确认

#### Scenario: 关闭终端中止确认
- **WHEN** 确认过程中用户关闭终端或插件卸载
- **THEN** 立即停止状态轮询与任何后续写入

#### Scenario: 退出后续聊
- **WHEN** Antigravity 已退出（macOS 钥匙串无登录条目或 Windows 身份为未配置），用户续聊已有任务
- **THEN** 拒绝启动并说明「尚未登录 Antigravity」及在「CLI Worker 设置 → Antigravity」点击「登录账号」，不启动进程、不改动会话与绑定

#### Scenario: 其他 CLI 与管理动作
- **WHEN** 打开其他 CLI 的账号终端，或 Antigravity 的管理动作
- **THEN** 不显示该引导、不写入任何内容
