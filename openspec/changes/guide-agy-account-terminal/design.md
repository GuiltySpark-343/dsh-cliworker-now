## Context

账号终端由 Host 通过宿主终端句柄运行原生 CLI，Client 只显示终端字节流和 Host 的 `AccountFrame`。agy 1.4.7 没有退出子命令，退出只能在已登录主界面输入 `/logout`；登录依次经过（可能的）文件夹信任、登录方式菜单、浏览器授权、粘贴授权码、回车。macOS 登录状态以钥匙串 `gemini`/`antigravity` 为准，Host 已能只读确认（`identity()`）。

## Decisions

### D1 引导由 Host 识别、固定文案

新增纯模块 `agy-account-guide.ts`：保存最近 4 KB 终端输出，去掉 CSI/OSC 等控制序列与全部空白并转小写后匹配固定标记（TUI 可能用光标移动代替空格）。识别到步骤后只发出 Host 固定的 `AccountGuide { step, tone, text }`；不转发、不渲染 CLI 输出，也不保存用户输入。登录步骤只前进不回退，菜单重绘不会把引导拉回上一步。

### D2 粘贴与回车的判定

用户写入仅在授权码步骤参与判定：含括号粘贴起始序列 `ESC[200~` 或单次写入 16 个以上字符视为粘贴，显示醒目的「授权码已粘贴，请按回车完成登录」；之后（或逐字键入后）的回车触发确认。授权码本身只经原有写入通路进入终端，不进入引导、日志或事件。

### D3 以原生账号状态确认登录与退出

回车后 Host 每 1.5 秒以 `identity()` 只读核对，最长 60 秒：`authenticated` 显示「已登录 Antigravity，可以关闭终端」；超时显示「暂未确认登录…」并允许粘贴新的授权码再次确认。退出写入命令后最长 20 秒：`unconfigured` 显示「已退出 Antigravity」并按正常关闭流程结束终端（含 D1 of `fix-account-terminal-zombie-close` 的前台 SIGTERM 与进程范围清理）；超时只提示查看终端，不再写入。轮询由会话的 `AbortController` 控制，终端关闭、停止或插件卸载时中止。

### D4 自动退出只写一条命令

仅 `antigravity` 的 `logout` 动作：识别到已登录主界面标记后，延迟 400 ms 写入 `/logout`，再延迟后写入回车，整个会话只写一次。屏幕显示未登录或信任询问时不写入任何内容；未登录直接提示「当前未登录 Antigravity，无需退出」并关闭终端。`manage` 动作和其他 CLI 不启用引导与写入。

主界面就绪标记 `? for shortcuts` 已由真实已登录界面的只读探测确认（见 D11）。

### D5 退出后续聊的提示

macOS 钥匙串条目缺失、Windows 身份为未配置时，账号绑定读取抛出固定说明「尚未登录 Antigravity，请在「CLI Worker 设置 → Antigravity」点击「登录账号」完成登录后再继续」，替代原先含义不清的「无法确认当前自身账号」，便于用户与主 Agent 判断下一步。Linux 缺少文件时行为不变。

## Risks

- agy 改版改动界面文字后，引导可能停在上一步或不出现；此时终端仍可照常操作，自动退出不会触发写入（只在识别到主界面时写），最坏情况退回手动输入。
- 授权码少于 16 个字符且逐字键入时不显示「已粘贴」，但回车仍会触发确认。

## 2026-10-26 修订：自制登录窗口

### D6 原生终端隐藏在插件窗口之后

`AccountTerminal` 对 Antigravity 的登录、退出挂载 `AgyAccountWizard`，xterm 仍创建并接收输出，但容器隐藏；隐藏期间不调用 `accountResize`，Host 按 `AGY_GUIDED_SIZE`（200 列 × 60 行）启动 PTY，避免 agy 自身滚动区把授权码提示挤出屏幕（实测 80 列时登录地址折成 10 行，提示位于不可见的第 18–27 行）。用户点「显示原生终端」后照常按可见尺寸适配。管理动作和其他 CLI 不变。

### D7 窗口写入的内容

窗口只在用户点击时写入：选择方式与信任各写一次回车（只在对应步骤可点）；提交授权码写 `ESC[200~<code>ESC[201~`（agy 开启了括号粘贴模式 `?2004h`），300 ms 后写回车。所有写入仍走原有 `accountWrite` 通路与 16 KB 上限，Host 引导照常据此进入确认。授权码只保存在输入框状态中，提交或卸载后不留存。

### D8 登录地址

Host 在登录动作中保留最近 8 KB 原始输出，从 OSC 8 超链接取目标地址，`new URL` 校验为 `https:`、主机 `accounts.google.com`、无用户信息才附在 `code` 步骤的 `guide.link`；Client 打开前再按同一规则校验，经 `window.open` 交给宿主外部浏览器。地址晚于提示到达时重发一次 `code` 步骤。

### D9 就绪判定不再依赖猜测文字

Host 在每次输出后重置 1.2 秒静止计时（自首次输出起最长 8 秒）。到期时若尚未识别任何步骤且画面不含信任、未登录、方式菜单、授权码提示，引导请求 Host 读取原生账号：退出动作已登录才写入 `/logout`，未登录提示无需退出并关闭；登录动作已登录显示「当前已登录」。`? for shortcuts` 仍作为退出的快速路径。

### D10 登录成功后结束原生终端

确认登录后 Host 发出 `signedIn` 并按正常关闭流程结束 agy（前台 SIGTERM 与进程范围清理），解除账号终端占用；窗口保留成功结果，点「完成」关闭弹窗。确认超时缩短为 20 秒。

### D11 已登录启动也会打印未登录行

真实已登录探测：agy 1.4.7 启动先显示「Welcome to the Antigravity CLI. You are currently not signed in.」与「Signing in...」，约 2 秒后才画出主界面（含账号、模型与 `? for shortcuts`）。因此「未登录」只以登录方式菜单（`Select login method`）判定，不能以该行判定；静止阈值取 3 秒（上限 10 秒），避免在登录检查的停顿中误判。`/logout` 写入回车后等待 1.5 秒：原生账号仍为已登录且画面未出现登录菜单时，再写一次回车（首个回车可能只接受了斜杠命令补全）；出现登录菜单后绝不再按回车，以免误启动登录。
