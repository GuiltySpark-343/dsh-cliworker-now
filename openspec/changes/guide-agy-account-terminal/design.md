## Context

账号终端由 Host 通过宿主终端句柄运行原生 CLI，Client 只显示终端字节流和 Host 的 `AccountFrame`。agy 1.4.7 没有退出子命令，退出只能在已登录主界面输入 `/logout`；登录依次经过（可能的）文件夹信任、登录方式菜单、浏览器授权、粘贴授权码、回车。macOS 登录状态以钥匙串 `gemini`/`antigravity` 为准，Host 已能只读确认（`identity()`）。

## Decisions

### D1 引导由 Host 识别、固定文案

新增纯模块 `agy-account-guide.ts`：保存最近 4 KB 终端输出，去掉 CSI/OSC 等控制序列与全部空白并转小写后匹配固定标记（TUI 可能用光标移动代替空格）。识别到步骤后只发出 Host 固定的 `AccountGuide { step, tone, text }`；不转发、不渲染 CLI 输出，也不保存用户输入。登录步骤只前进不回退，菜单重绘不会把引导拉回上一步。

### D2 粘贴与回车的判定

用户写入仅在授权码步骤参与判定：含括号粘贴起始序列 `ESC[200~` 或单次写入 16 个以上字符视为粘贴，显示醒目的「授权码已粘贴，请按回车完成登录」；之后（或逐字键入后）的回车触发确认。授权码本身只经原有写入通路进入终端，不进入引导、日志或事件。

### D3 以原生账号状态确认登录与退出

回车后 Host 每 1.5 秒以 `identity()` 只读核对，最长 60 秒：`authenticated` 显示「已登录 Antigravity，可以关闭终端」；超时显示「暂未确认登录…」并允许粘贴新的授权码再次确认。退出写入命令后最长 20 秒：`unconfigured` 显示「已退出 Antigravity」并按正常关闭流程结束终端（含 D1 of `fix-account-terminal-zombie-close` 的前台 SIGTERM 与进程范围清理）；超时只提示查看终端，不再写入。轮询由会话的 `AbortController` 控制，终端关闭、停止或插件卸载时中止。

### D4 自动退出只写一条命令

仅 `antigravity` 的 `logout` 动作：识别到已登录主界面标记后，延迟 400 ms 写入 `/logout`，再延迟后写入回车，整个会话只写一次。屏幕显示未登录或信任询问时不写入任何内容；未登录直接提示「当前未登录 Antigravity，无需退出」并关闭终端。`manage` 动作和其他 CLI 不启用引导与写入。

主界面就绪标记来自真实已登录界面的只读探测；探测前使用的占位标记只在单元测试的合成画面中验证。

### D5 退出后续聊的提示

macOS 钥匙串条目缺失、Windows 身份为未配置时，账号绑定读取抛出固定说明「尚未登录 Antigravity，请在「CLI Worker 设置 → Antigravity」点击「登录账号」完成登录后再继续」，替代原先含义不清的「无法确认当前自身账号」，便于用户与主 Agent 判断下一步。Linux 缺少文件时行为不变。

## Risks

- agy 改版改动界面文字后，引导可能停在上一步或不出现；此时终端仍可照常操作，自动退出不会触发写入（只在识别到主界面时写），最坏情况退回手动输入。
- 授权码少于 16 个字符且逐字键入时不显示「已粘贴」，但回车仍会触发确认。
