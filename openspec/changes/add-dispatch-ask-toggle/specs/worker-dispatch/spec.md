## ADDED Requirements

### Requirement: 调用前询问开关
设置页 SHALL 为每个项目和 CLI 提供“调用前询问模型”开关，默认开启。开关 MUST 按项目和 CLI 私有保存；缺少记录或旧版本配置 MUST 视为开启。关闭后，新主对话派遣该 CLI 时，只有在项目已保存完整设定（模型、强度、角色、账号绑定）且在当前账号和目录下仍有效时，才 SHALL 不弹出沿用或选型问题卡而直接使用该设定；该设定 MUST 仍通过实时授权、宿主权限、CLI 开关与项目一致性检查。没有完整设定或设定失效时 MUST 回退到完整选型，不得猜测模型、强度或角色，不得套用其他 CLI 的设定。

#### Scenario: 默认询问
- **WHEN** 用户从未修改开关，或升级后旧配置缺少该记录
- **THEN** 开关显示为开启，新主对话派遣时与原流程一致，先询问沿用或完整选型

#### Scenario: 关闭后直接启动
- **WHEN** 项目和 CLI 已关闭调用前询问，且已保存的完整设定仍有效
- **THEN** 新主对话派遣不出现任何问题卡，任务使用该设定的模型、强度与角色，且该对话记住此设定

#### Scenario: 无完整设定时回退
- **WHEN** 已关闭询问，但项目只在设置页保存了模型和强度、从未确认角色，或从未保存设定
- **THEN** 进入完整选型问题卡；完成后保存完整设定，后续新主对话可直接使用

#### Scenario: 设定失效时回退
- **WHEN** 已关闭询问，但保存的模型不在当前目录、强度不受支持或账号绑定已改变
- **THEN** 不静默替换模型或账号，进入完整选型；无可用目录时返回简短错误且不启动

#### Scenario: 实时授权失败
- **WHEN** 已关闭询问且设定通过目录检查，但实时授权发现账号或模型在检查期间改变
- **THEN** 返回明确错误且不启动任务，不保存部分设定

#### Scenario: 开关作用范围
- **WHEN** 用户在一个项目或 CLI 关闭询问
- **THEN** 其他项目、其他 CLI 仍按各自开关处理；同会话互斥、同目录写任务串行与宿主规划/只读拒绝不变

## MODIFIED Requirements

### Requirement: 项目设定与主对话确认
首次派遣 SHALL 询问模型、模型支持的思考强度及角色并保存完整设定。相同项目和 CLI 的新主对话 SHALL 先询问是否沿用以前设定；唯一例外是该项目和 CLI 已关闭调用前询问且已保存设定仍有效，此时 SHALL 直接沿用。同一主对话后续派遣 SHALL 使用自身已经确认的设定，Host 重启后仍有效。明确选择不使用角色 SHALL 视为完整设定。

#### Scenario: 新对话沿用
- **WHEN** 项目和 CLI 已有有效完整设定，新主对话首次派遣并选择沿用
- **THEN** 只出现一次沿用询问，任务使用既有模型、强度与角色

#### Scenario: 新对话重新选择
- **WHEN** 新主对话选择不沿用
- **THEN** 询问模型、强度及角色，完成后更新该对话和项目设定

#### Scenario: 关闭询问时新对话直接沿用
- **WHEN** 项目和 CLI 已关闭调用前询问，且已有有效完整设定
- **THEN** 新主对话首次派遣不出现沿用询问，直接使用既有模型、强度与角色

#### Scenario: 同一对话继续派遣
- **WHEN** 已确认设定的主对话再次派遣相同 CLI
- **THEN** 不再次提问，其他对话修改项目默认不改变该对话已确认设定

#### Scenario: 项目或 CLI 不同
- **WHEN** 请求切换项目或 CLI
- **THEN** 对应设定独立读取与确认，不跨项目、CLI 或主对话代答

#### Scenario: 账号或模型变化
- **WHEN** 已确认设定的账号来源改变或模型、强度不再有效
- **THEN** 不静默替换账号或模型；关闭询问且项目设定仍有效时使用项目设定，否则可选目录有效时进入完整选型，无可用目录时返回简短错误且不启动

#### Scenario: 设置页更新默认
- **WHEN** 用户在设置页更改项目的模型和强度
- **THEN** 后续新主对话沿用更新后的默认及已确认角色，已有对话与 Worker 的快照保持不变
